# CHEMISTRY LAB
Інтерактивний сайт українською мовою, хімія, 9 клас.

## Запуск
Потрібні Node.js 20.19+ та доступ до npm registry.

```sh
npm install
npm run dev
```

Перевірка TypeScript і production-збірка: `npm run build`.
Попередній перегляд збірки: `npm run preview`.

## Навчальна модель
Відносна швидкість:
`exp(24000 / 8.314 * (1 / 293.15 - 1 / (T + 273.15))) * c * S * k * n`.
Базовий стан: 20 °C, c = S = n = 1, без каталізатора.
Каталізатор умовно має множник 2, сценарії природи реагентів — 0.6, 1, 1.5.
Це детермінована ілюстрація, а не експериментальні дані чи універсальний кінетичний закон. Графік якісний і незалежний від числового множника каталізатора. Рух частинок декоративно ілюструє зміни, не розв’язує рівняння молекулярної динаміки.

Усі чинники зберігаються між вкладками; кнопка скидання відновлює базовий стан. Пауза зупиняє частинки. Друк відкриває системний діалог; виберіть A4. Стилі друку формують стислий науковий постер. Анімації враховують prefers-reduced-motion.

## Статус перевірки
